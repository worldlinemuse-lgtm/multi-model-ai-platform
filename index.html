A2.6: Python/SQLite offline control plane, synthetic quota accounting and local encrypted key vault. Historical release is preserved in the project’s Persistent File Library; it is not a hosted API service.

What the sandbox means

The runner executes JavaScript in a separate sandboxed iframe without same-origin permissions; a restrictive Content Security Policy blocks network connections. This is browser-based code execution, not a full Linux virtual machine.
