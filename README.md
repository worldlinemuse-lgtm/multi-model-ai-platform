# Multi-Model AI Platform

An experimental, browser-first environment for human-directed multi-model AI orchestration, guided onboarding for legitimately recurring-free API access, a browser IDE, and sandboxed code execution.

## Current status

Development artifacts and verified historical releases are preserved in the project's Persistent File Library under `/Multi-Model AI Platform/`. The B0.1 browser bootstrap has been prepared for repository publication. This repository is separate from Muse's website.

This README initializes the dedicated repository and verifies write access. It does not represent a deployed application or a live AI API integration.
